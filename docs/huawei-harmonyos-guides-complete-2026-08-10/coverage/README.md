# 覆盖审计说明

本目录保存官网左侧菜单与逐页读取的机器可审计证据。

当前快照：2026-08-10。最终结果为 5,720 个 UI 节点、1,059 个可展开分支、5,694 个正文入口；5,694 篇正文全部成功读取，失败和待处理均为 0，第二次官网目录读取与首次快照一致。

完成判据：

- 左侧目录所有折叠分支均已展开，折叠节点数为 0。
- 每个带正文的菜单节点都有唯一 `treeKey`、菜单路径和官方 URL。
- 每个规范化正文 URL 都有终态记录：成功、重定向、无正文、受限或失败。
- 成功页面保存标题、更新时间、正文长度、内容哈希、标题层级、代码块、表格、提示框和图片统计。
- 失败页面经过独立补跑；未访问数和未解释失败数必须为 0，才能声明全量完成。
- 完成后重新读取一次官网目录，检查采集期间是否新增或删除页面。

## 关键文件

| 文件 | 用途 |
|---|---|
| `audit-report.md/json` | SQLite、菜单、正文、压缩数据、哈希、错误页与二次目录差异的最终审计 |
| `crawl-report.md` | 逐页读取数量和内容结构统计 |
| `menu-tree.md` | 官网左侧菜单完整层级 |
| `menu-inventory.json/csv` | 节点、父子关系、菜单路径、slug 与 URL |
| `page-status.csv` | 每个正文页面的终态、更新时间、哈希与结构计数 |
| `heading-index.csv` | 全部正文标题与锚点索引 |
| `code-source-index.csv` | 代码块语言、来源、长度、哈希和短定位信息 |
| `admonition-index.csv` | 提示/警告类型、长度、哈希和短定位信息 |
| `topic-statistics.csv` | 按官方根目录与直接子类汇总的体量 |
| `theme-coverage-audit.md` | 用户截图中 21 个根菜单到综合章节的逐项交叉检查 |
| `handbook-validation.md/json` | 最终主文档、逐页索引、链接、围栏、版本与覆盖率验证 |
| `crawl.sqlite3` | 完整机器证据；包含压缩后的结构化抽取、正文与 HTML |

`crawl.sqlite3` 用于本地追溯和再生成，不建议直接作为日常 AI 上下文。日常使用应先读主 `README.md`，再通过 `FULL_PAGE_DIGESTS.md`、标题索引和官方 URL 定位。
