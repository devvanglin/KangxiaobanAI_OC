# 康小伴（Kangxiaoban）后端与展示 · 项目进展文档

> 更新时间：2026-08-27
> 范围：本次系列开发（从「纯前端 mock 原型」到「可运行的后端 + 展示 + 鸿蒙多端」）的全部工作与成果。

## 0. 一句话总览

康小伴从**只有本地 mock、无后端**的原型，升级为一套**可真实运行的养老机构全模块后端**（Go + SQLite/MySQL），并配齐**全国展示壳（落地页 + 实时大屏）**、**护工端 network 对接层**、**独立家属端鸿蒙项目**与**真实毫米波雷达物联网接入**。

## 1. 后端交付（progress 里程碑）

| 里程碑 | 内容 | 状态 |
|---|---|---|
| **M0 骨架/登录** | Go(Gin+GORM) 工程骨架、SQLite(开发)/MySQL(生产) 切换、JWT 登录、RBAC、审计、3角色+默认 admin | ✅ |
| **M1 核心业务** | 长者档案、房间/床位、护理任务、体征(异常自动判定) 全 CRUD + 种子 | ✅ |
| **M2 实时层** | WebSocket(Hub)+任务/体征实时广播、`/demo/push`、鸿蒙 `network/` 层 | ✅ |
| **M3 物联网** | MQTT 订阅雷达(EMQX 192.168.100.110)、字段归一化、规则引擎分级告警(跌倒/呼吸/心率/离床)、处置闭环、离线扫描 | ✅ |
| **M4 业务闭环** | 排班、交接班、费用账单(自动生成/缴费/余额/流水)、用药、审计 | ✅ |
| **M5 补充模块** | 药物库存(出入库)、餐饮订餐、家属账号(带数据隔离) | ✅ |
| **P0 优化** | 真 AI 网关(`/ai/chat`)、应急自动升级、演示数据播种 | ✅ |

### 后端能力全景
- **认证/授权**：JWT + RBAC（角色权限表），操作审计落库
- **长者/护理**：档案、床位占用、任务、体征、医嘱（用药）、健康记录
- **运营**：费用账单、排班交接、餐饮订餐、药物库存
- **IoT**：毫米波雷达订阅、归一化、规则告警、分级+升级、WS 实时推送
- **AI 网关**：可插拔 provider（local 离线 / http 接真实模型）
- **多端数据隔离**：家属账号按「绑定长者」过滤体征/账单/告警

## 2. 全国展示壳（非鸿蒙端）

单进程 `go run ./cmd/server` 同时托管 **后端 API + 落地页 + 实时大屏**：

- `/` —— 落地页（Stripe 大厂极简风：Hero + 6 大能力 + 四层架构 + CTA）
- `/dashboard.html` —— 实时大屏（总览/费用/排班三视图，读真摘要；暗色实时告警流 + 设备表）
- `/api/v1/*` —— 全部业务 API
- 演示数据播种开关 `KXB_SEED_DEMO=true`：空库首启自动生成设备/告警/账单，大屏开即有数据

## 6. 如何一键运行

```bash
# 进入后端
cd kangxiaoban-service
# （可选）复制 .env.example → .env 修改配置
go run ./cmd/server
# 打开 http://127.0.0.1:8080/  （落地页）
#     http://127.0.0.1:8080/dashboard.html （实时大屏）
```
