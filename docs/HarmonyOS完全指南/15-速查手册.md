## 2. 状态管理 V2 全表

| 装饰器 | 加在哪 | 干什么 | 注意 |
|---|---|---|---|
| `@ComponentV2` | struct | V2 组件 | 不能和 V1 装饰器混用 |
| `@Entry` | struct | 路由页面 | 必须写进 `main_pages.json` |
| `@Local` | 字段 | 私有状态 | 必须有初值，父不能传 |
| `@Param` | 字段 | 父传子 | 子**只读** |
| `@Require` | 配 `@Param` | 必填 | 父不传编译报错 |
| `@Once` | 配 `@Param` | 只接收初值 | 之后子可改 |
| `@Event` | 字段 | 子回调父 | **必须有默认空函数** |
| `@Monitor('a','b')` | 方法 | 监听变化 | 支持嵌套路径 |
| `@Computed` | getter | 派生值（缓存） | 必须无副作用 |
| `@Provider('k')` | 字段 | 提供给后代 | — |
| `@Consumer('k')` | 字段 | 消费祖先 | 名字错会静默失效 |
| `@ObservedV2` | class | 可观察类 | — |
| `@Trace` | 类字段 | 该字段变化触发 UI | 只能在 `@ObservedV2` 里 |
| `@Builder` | 方法 | UI 片段 | 用 `this.foo()` 调 |
| `@BuilderParam` | 字段 | UI 插槽 | 父传 Builder 进来 |
| `@Styles` | 方法 | 通用样式复用 | 只能写通用属性 |
| `@Extend(Text)` | 顶层函数 | 组件专属样式 | 必须写在文件顶层 |
| `@ReusableV2` | struct | 组件复用 | 配 LazyForEach |

**禁用（V1）**：`@State` `@Prop` `@Link` `@Observed` `@ObjectLink` `@Watch` `@Provide` `@Consume` `@StorageLink` `@StorageProp`

// —— 全局状态标准写法 ——

}

    () => { this.isShow = false; });

@Param @Require geometryId: string;

  Column() { /* 详情内容 */ }
    .geometryTransition(this.geometryId)          // ★无 follow
    .transition(TransitionEffect.OPACITY)          // ★必须

.bindContentCover(this.isShow, this.coverBuilder, {
  modalTransition: ModalTransition.NONE,          // ★必须 NONE
  backgroundColor: 'rgba(0,0,0,0)',               // ★必须透明
  onWillDismiss: (a: DismissContentCoverAction) => {
    if (a.reason === DismissReason.PRESS_BACK) { this.close(); }
  }

// ⑤ Navigation 场景（关掉默认转场）
this.pathStack.pushPath({ name: 'DetailPage', param }, false);
this.pathStack.pop(false);

onWillDismiss 处理 PRESS_BACK / 动态 ID 存 @Local / 终点用 @Param 接 ID / 焦点管理

import { BreakpointType, BreakpointUtil } from '../util/BreakpointSystem';

// 断点阈值
WidthBreakpoint.WIDTH_XS   // < 320vp

WidthBreakpoint.WIDTH_MD   // 600 ~ 840vp     折叠屏展开 / 小平板
WidthBreakpoint.WIDTH_LG   // 840 ~ 1440vp    平板 / PC

.stateStyles({ normal: this.normalStyle, pressed: this.pressedStyle,
               focused: this.focusStyle, disabled: this.disabledStyle })

## 15. ArkTS 禁用清单

| 禁用 | 替代 |
|---|---|
| `var` | `let` / `const` |
| `any` / `unknown` | 具体类型 / 联合类型 / `ESObject` |
| `obj['key']` | `obj.key` / `Map` |
| `delete obj.x` | `Map.delete` |
| `'x' in obj` | `obj.x !== undefined` |
| 函数重载 | 联合类型参数 |
| `fn.bind/call/apply` | 箭头函数 |
| `eval` / `new Function` | — |
| `Symbol` | — |
| `globalThis` | `AppStorageV2` |
| `with` | — |
| `require` / `module.exports` | `import` / `export` |
| 独立函数里 `this` | 类方法 / 箭头函数 |
| 索引签名 `[k: string]: T` | `Map` / `Record` |
| 无类型对象字面量 | 加 `interface` 或 `as` |
| 结构化类型 | 显式 `implements` |

## 17. 「界面不刷新」10 步排查

```
1. 变量有 @Local / @Param / @Trace 吗
2. 是不是在改只读的 @Param（要 @Once 或让父改）
3. 类字段有 @Trace 吗
4. 嵌套对象每一层都是 @ObservedV2 吗
5. 数组元素是 @ObservedV2 吗（否则整体替换 [...arr]）
6. ForEach/Repeat 的 key 是稳定唯一的吗（别用 index）
7. 回调用的是箭头函数吗（this 会不会丢）
8. @Consumer 的别名和 @Provider 一致吗
9. @Monitor 的路径字符串拼对了吗
10. 改的是 AppStorageV2 里那个实例，还是新 new 的
```

## 18. 本项目开发准则（10 条）

```
1. 只改 KangxiaobanAI/products/entry/src/main/ets 下的文件
2. 只用状态管理 V2，禁用一切 V1 装饰器
3. 全局状态只放 GlobalInfoModel，只放会话/环境/窗口/角色四类
4. role 是显示用的，不是权限
5. 不新增一级 Tab
6. 断点从 GlobalInfoModel 读，不自己查窗口
7. 定时器/监听器成对注册和清理
8. 资源用 $r()，不硬编码颜色文字
9. 不把本地数组操作说成「已保存到服务器」
10. 构建状态四档如实说：已实现 / 已构建验证 / 已真机验证 / 仅规划
```
