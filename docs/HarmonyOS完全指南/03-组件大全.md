# 一、基础显示组件

## Text —— 文本

**干什么**：显示一段文字。最常用的组件，没有之一。

**最小例子**：

```typescript
Text('你好世界')
```

**常用属性**：

```typescript
Text('内容')
  .fontSize(16)                                    // 字号（默认 fp）
  .fontSize($r('sys.float.Body_M'))                // 用系统 token（推荐）
  .fontColor($r('sys.color.font_primary'))         // 颜色
  .fontWeight(FontWeight.Bold)                     // 粗细：Lighter/Normal/Regular/Medium/Bold/Bolder，或 100~900
  .fontStyle(FontStyle.Italic)                     // 斜体
  .fontFamily('HarmonyOS Sans')                    // 字体
  .lineHeight(24)                                  // 行高
  .letterSpacing(0.5)                              // 字间距
  .textAlign(TextAlign.Center)                     // Start/Center/End/JUSTIFY
  .maxLines(2)                                     // 最多几行
  .textOverflow({ overflow: TextOverflow.Ellipsis })  // 超出显示 ...
  .ellipsisMode(EllipsisMode.END)                  // 省略号位置：START/CENTER/END
  .decoration({ type: TextDecorationType.LineThrough })  // 删除线/下划线
  .textCase(TextCase.UpperCase)                    // 大小写转换
  .copyOption(CopyOptions.LocalDevice)             // 允许长按复制
  .baselineOffset(0)
  .minFontSize(12).maxFontSize(20)                 // 自适应字号范围
  .textIndent(20)                                  // 首行缩进
```

**本项目的真实用法**（`component/HealthListCard.ets`）：

```typescript
Text(this.cardData.title)
  .fontSize($r('sys.float.Title_M'))
  .fontColor($r('sys.color.font_primary'))
  .fontWeight(FontWeight.Bold)
  .margin({ bottom: $r('sys.float.padding_level4') })
  .maxLines(1)
  .ellipsisMode(EllipsisMode.END)
  .textOverflow({ overflow: TextOverflow.Ellipsis })
```

**坑**：

1. **`maxLines` 必须配合 `textOverflow` 用**，光设 `maxLines` 超出部分会被直接裁掉而不是显示 `...`。
2. `Text` 默认会**自动换行**。不想换行就 `.maxLines(1)`。
3. `Text` 在 `Row` 里如果太长会把兄弟组件挤出去，要加 `.layoutWeight(1)` 让它自己压缩。
4. **模板字符串里插值要用 `${}`**：`Text(\`共 ${this.count} 条\`)`。

## Span / ContainerSpan / ImageSpan / SymbolSpan —— 文本片段

**干什么**：在一个 `Text` 里混排不同样式的文字、图片、图标。

```typescript
Text() {                          // ← 注意 Text 后面用大括号，不传字符串
  Span('普通 ')
  Span('加粗红色').fontWeight(FontWeight.Bold).fontColor(Color.Red)
  ImageSpan($r('app.media.icon')).width(16).height(16)
  SymbolSpan($r('sys.symbol.heart_fill')).fontColor([Color.Red])
}
```

**坑**：`Span` 只能放在 `Text` 里，不能单独用。

## RichText —— HTML 富文本

```typescript
RichText('<h1>标题</h1><p style="color:red">红字</p>')
  .width('100%')
```

**坑**：性能不如 `Text` + `Span`，只在必须渲染 HTML 时用。

## RichEditor —— 可编辑富文本

**干什么**：像微信输入框那样，可以插入图片、@某人、表情的编辑器。

```typescript
RichEditor({ controller: this.controller })
  .onReady(() => {
    this.controller.addTextSpan('初始内容', { style: { fontColor: Color.Black } })
  })
  .height(200)
```

## Image —— 图片

```typescript
Image($r('app.media.logo'))                 // 本地资源
Image($rawfile('images/pic.png'))           // rawfile 原始文件
Image('https://example.com/a.png')          // 网络图片（需要网络权限）
Image(this.pixelMap)                        // PixelMap 对象
```

**常用属性**：

```typescript
Image($r('app.media.logo'))
  .width(100).height(100)
  .objectFit(ImageFit.Cover)     // Contain(完整显示) / Cover(填满裁剪) / Fill(拉伸) / None / ScaleDown / Auto
  .borderRadius(8)
  .interpolation(ImageInterpolation.High)  // 缩放插值质量
  .alt($r('app.media.placeholder'))        // 加载中的占位图
  .syncLoad(false)                          // 是否同步加载（默认异步）
  .draggable(false)
  .onComplete((e) => { })
  .onError((e) => { })
```

**坑**：

1. **网络图片必须在 `module.json5` 声明 `ohos.permission.INTERNET` 权限**，否则不显示且无报错。
2. `objectFit` 默认是 `Cover`，图片会被裁。想完整显示用 `Contain`。
3. 大图不做 `.width/.height` 限制会占用巨量内存。

## SymbolGlyph —— 系统矢量图标

**干什么**：鸿蒙的图标系统（类似 iOS 的 SF Symbols）。**本项目所有图标都用它。**

```typescript
SymbolGlyph($r('sys.symbol.house_fill'))
  .fontSize(24)                                // 图标大小用 fontSize 控制
  .fontColor([$r('sys.color.icon_primary')])   // ★ 参数为数组，支持多色图标分层着色
  .renderingStrategy(SymbolRenderingStrategy.SINGLE)   // SINGLE(单色) / MULTIPLE_COLOR(多色) / MULTIPLE_OPACITY(多层透明度)
  .effectStrategy(SymbolEffectStrategy.SCALE)  // 动效
```

**本项目常用图标名**（都是 `sys.symbol.*`）：

```
house_fill              房子（首页）
person_2_fill           两个人（长者）
person_fill             一个人
person_crop_circle_fill 圆形头像（我的）
message_on_message_fill 消息
chevron_left/right/down/up  箭头
xmark                   关闭 ×
magnifyingglass         放大镜（搜索）
bell                    铃铛（通知）
gearshape               齿轮（设置）
list_bullet             列表
line_3_horizontal       三横线（菜单）
square_and_pencil       编辑/新建
doc_text                文档
calendar_badge_clock    日程
questionmark_circle     帮助
lock_fill               锁
eye / eye_slash         显示/隐藏密码
hammer_fill             锤子（开发中）
```

**坑**：

1. **`fontColor` 参数是数组 `[color]`，不是单个颜色**。写成 `.fontColor(Color.Red)` 会类型报错。
2. 大小用 `fontSize` 不是 `width/height`。
3. 图标名写错不会报错，只是不显示。

## Blank —— 弹性空白

**干什么**：在 `Row`/`Column` 里占据剩余空间，把兄弟组件推开。

```typescript
Row() {
  Text('左')
  Blank()          // ← 吃掉中间所有空间
  Text('右')
}
.width('100%')
```

**本项目的用法**（`pages/MainPage.ets` 的 PC 顶栏）：

```typescript
Row({ space: 16 }) {
  Row({ space: 12 }) { /* 左侧标题 */ }
  Blank()                                  // ← 中间撑开
  Row({ space: 8 }) { /* 右侧图标 */ }
}
```

也可以配合 `layoutWeight` 做上下居中（`pages/LoginPage.ets`）：

```typescript
Column() {
  Blank().layoutWeight(1)      // 上面的弹性空间
  Column() { /* 表单 */ }
  Blank().layoutWeight(1)      // 下面的弹性空间
}
```

# 二、交互输入组件

## Button —— 按钮

**三种写法**：

```typescript
// ① 文字按钮
Button('确定')

// ② 带配置
Button('确定', { type: ButtonType.Capsule, stateEffect: true })

// ③ 自定义内容（最灵活）
Button() {
  Row({ space: 8 }) {
    SymbolGlyph($r('sys.symbol.plus')).fontSize(16)
    Text('新增')
  }
}
```

**`ButtonType`**：`Capsule`（胶囊，默认）/ `Circle`（圆）/ `Normal`（直角矩形）/ `ROUNDED_RECTANGLE`

**常用属性**：

```typescript
Button('登录')
  .width('100%')
  .height(54)
  .backgroundColor($r('app.color.brand_blue'))
  .borderRadius(16)
  .enabled(this.canSubmit)          // 是否可点击
  .opacity(this.canSubmit ? 1 : 0.4)
  .stateEffect(true)                // 按下是否有默认按压效果
  .onClick(() => { })
```

**本项目的真实例子**（`pages/LoginPage.ets`，加载中切换内容）：

```typescript
Button() {
  if (this.isLoading) {
    LoadingProgress().width(22).height(22).color($r('app.color.text_on_brand'))
  } else {
    Text('登录').fontSize($r('sys.float.Title_S'))
      .fontWeight(FontWeight.Medium).fontColor($r('app.color.text_on_brand'))
  }
}
.width('100%')
.height(54)
.backgroundColor($r('app.color.brand_blue'))
.borderRadius(16)
.enabled(!this.isLoading && this.account.length > 0 && this.password.length > 0)
.opacity((!this.isLoading && this.account.length > 0 && this.password.length > 0) ? 1 : 0.4)
.animation({ duration: 200, curve: Curve.EaseInOut })
.onClick(() => { this.handleLogin(); })
```

**坑**：`.enabled(false)` 会同时禁用点击**和**变灰。如果只想变灰但仍可点，用 `.opacity()` + 自己判断。

## TextInput —— 单行输入框

```typescript
TextInput({ placeholder: '请输入', text: this.value })
  .type(InputType.Normal)      // Normal / Password / Email / Number / PhoneNumber / USER_NAME / NEW_PASSWORD
  .placeholderColor($r('sys.color.font_tertiary'))
  .placeholderFont({ size: 16 })
  .fontSize(16)
  .fontColor($r('sys.color.font_primary'))
  .caretColor($r('app.color.brand_blue'))    // 光标颜色
  .maxLength(20)
  .showPasswordIcon(false)                    // 密码框是否显示小眼睛
  .enableKeyboardOnFocus(true)
  .backgroundColor(Color.Transparent)
  .onChange((val: string) => { this.value = val; })
  .onSubmit((key: EnterKeyType) => { })
  .onFocus(() => { })
  .onBlur(() => { })
```

**两种数据绑定方式**（本项目两种都用了）：

```typescript
// 方式 A：手动同步（LoginPage.ets）—— 可以在同步前做处理
TextInput({ placeholder: '手机号 / 工号', text: this.account })
  .onChange((val: string) => { this.account = val; })

// 方式 B：$$ 双向绑定（TabPageView.ets）—— 更简洁
TextInput({ placeholder: '搜索姓名或房间号', text: $$this.residentSearch })
```

**密码框的完整实现**（`pages/LoginPage.ets`）：

```typescript
Row({ space: 12 }) {
  SymbolGlyph($r('sys.symbol.lock_fill')).fontSize(18).fontColor([$r('sys.color.icon_tertiary')])

  TextInput({ placeholder: '密码', text: this.password })
    .type(this.showPassword ? InputType.Normal : InputType.Password)   // ← 切换类型
    .showPasswordIcon(false)                                            // ← 关掉系统的眼睛，自己画
    .layoutWeight(1)
    .backgroundColor(Color.Transparent)
    .padding({ left: 0, right: 0 })
    .onChange((val: string) => { this.password = val; })

  Row() {
    SymbolGlyph(this.showPassword ? $r('sys.symbol.eye') : $r('sys.symbol.eye_slash'))
      .fontSize(18).fontColor([$r('sys.color.icon_secondary')])
  }
  .width(32).height(32)
  .onClick(() => { this.showPassword = !this.showPassword; })
}
.width('100%').height(56)
.padding({ left: 20, right: 12 })
.backgroundColor($r('sys.color.comp_background_secondary'))
.borderRadius(16)
```

**坑**：

1. **`TextInput` 自带 padding 和背景**，想自定义外观必须 `.backgroundColor(Color.Transparent).padding({left:0,right:0})`，然后用外层 `Row` 画背景。这是本项目的通用做法。
2. **键盘弹起会顶起页面**。控制方式见第 06 章「键盘适配」。
3. `.type(InputType.Password)` 时系统默认显示眼睛图标，要自定义就 `.showPasswordIcon(false)`。

**嵌套滚动的坑（本项目遇到过）**：

`component/HealthListCard.ets` 里 `List` 嵌在外层 `Scroll` 里，需要：

```typescript
List({ space: 0 }) { /* ... */ }
  .nestedScroll({
    scrollForward: NestedScrollMode.PARENT_FIRST,    // 优先滚外层
    scrollBackward: NestedScrollMode.PARENT_FIRST
```

**`NestedScrollMode` 四个值**：

| 值 | 含义 |
|---|---|
| `SELF_ONLY` | 只有自己滚，不传给父 |
| `SELF_FIRST` | 自己先滚，滚到头再给父 |
| `PARENT_FIRST` | 父先滚，父滚到头再自己滚 |
| `PARALLEL` | 父子同时滚 |

# 十一、弹窗类（不是组件，是方法）

## `bindSheet` —— 半模态面板（从底部升起）

```typescript
Column() { /* 触发区域 */ }
  .bindSheet(this.isOpen, this.sheetBuilder, {
    detents: [SheetSize.LARGE, SheetSize.MEDIUM],   // 支持的高度档位（可拖拽切换）
    height: SheetSize.FIT_CONTENT,                  // 或固定高度
    showClose: true,                                 // 显示关闭按钮
    dragBar: true,                                   // 显示顶部拖拽条
    title: { title: '标题', subtitle: '副标题' },
    backgroundColor: $r('sys.color.background_secondary'),
    preferType: SheetType.BOTTOM,                    // BOTTOM / CENTER / POPUP
    onDisappear: () => { this.isOpen = false; }      // 必须在这里同步状态
  })
```

**`SheetSize`**：`MEDIUM`（半屏）/ `LARGE`（大屏）/ `FIT_CONTENT`（内容高度）

**本项目的真实例子**（`component/TabPageView.ets`）：

```typescript
private quickRowSheetOptions(item: QuickListRow): SheetOptions {
  if (this.allTasks().some((task: CareTask) => task.id === item.id)) {
    return {
      detents: [SheetSize.LARGE, SheetSize.MEDIUM],   // 任务详情内容多，用大档位
      showClose: true, dragBar: true,
      title: { title: item.title },
      backgroundColor: $r('sys.color.background_secondary'),
      onDisappear: () => { this.isQuickRowSheetOpen = false; }
    };
  }
  return {
    height: SheetSize.FIT_CONTENT,                     // 其它内容少，贴合内容
    showClose: true, dragBar: true,
    title: { title: item.title },
    backgroundColor: $r('sys.color.background_secondary'),
    onDisappear: () => { this.isQuickRowSheetOpen = false; }
  };
}
```

**坑**：

1. **`onDisappear` 里必须把控制变量置回 `false`**，否则用户下滑关闭后状态没同步，再点就打不开了。
2. `bindSheet` 挂在哪个组件上，就以哪个组件为锚点。挂在列表项上时要注意条件：
   `this.isQuickRowSheetOpen && this.selectedQuickRowId === item.id`（只有选中项才展开）。

## `bindContentCover` —— 全屏模态覆盖

```typescript
Column() { /* 内容 */ }
  .bindContentCover(this.isShow, this.coverBuilder, {
    modalTransition: ModalTransition.NONE,       // NONE / DEFAULT(上下滑) / ALPHA(淡入淡出)
    backgroundColor: 'rgba(0,0,0,0)',
    onWillDismiss: (action: DismissContentCoverAction) => {
      if (action.reason === DismissReason.PRESS_BACK) {
        this.closeIt();
      }
    }
  })
```

**一镜到底的关键**：`modalTransition: ModalTransition.NONE` 关掉默认转场，
把动画完全交给 `geometryTransition`。详见第 06 章。

**本项目的真实例子**（`component/TabPageView.ets`）：

```typescript
.bindContentCover(this.isResidentDetailShow, this.residentDetailCover, {
  modalTransition: ModalTransition.NONE,
  backgroundColor: 'rgba(0,0,0,0)',
  onWillDismiss: (action: DismissContentCoverAction) => {
    if (action.reason === DismissReason.PRESS_BACK) {
      this.closeResidentDetail();
    }
  }
})
```

# 十三、本章速记卡

| 我要 | 写法 |
|---|---|
| 竖排 | `Column({space: 12}) { }` |
| 横排 | `Row({space: 8}) { }` |
| 叠加 | `Stack({alignContent: Alignment.Center}) { }` |

| 滚动 | `Scroll() { Column() { } }` |
| 列表 | `List() { ForEach/Repeat }` |
| 网格 | `Grid().columnsTemplate('1fr 1fr')` |
| 瀑布流 | `WaterFlow() { FlowItem() {} }` |

| 底部弹窗 | `.bindSheet(bool, builder, options)` |
| 全屏浮层 | `.bindContentCover(bool, builder, {modalTransition: ModalTransition.NONE})` |
