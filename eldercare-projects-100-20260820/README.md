# 智慧养老项目 100 个：源码、部署与验收

本目录是 2026-08-20 启动的独立交付目录。

验收状态严格区分：

- `discovered`：已发现并记录来源；
- `cloned`：源码已完整拉取；
- `build-verified`：真实构建成功；
- `http-verified`：业务入口收到可接受的 HTTP 响应；
- `login-verified`：使用记录的账号完成真实登录；
- `failed`：已记录可定位的失败原因。

源码将存放在 `repos/`，规范化清单和逐项验收结果将存放在 `manifests/`，远端部署工具存放在 `tools/`。服务器密码、令牌和私钥不得写入本目录。
