# 《今日照护任务卡》90 分钟教案

## 一、课程目标

学生完成课程后能够：

1. 区分 ArkTS、ArkUI、组件和状态；
2. 看懂 `Column`、`Row`、`Text` 和 `Button`；
3. 使用 `@Local` 保存父组件状态；
4. 理解 `@Param` 是只读输入；
5. 使用 `@Event` 通知父组件；
6. 完成饮水计数和任务状态切换。

核心口诀：

> 父组件管数据，子组件管展示；数据向下传，事件向上传。

## 二、课前准备

- 教师提前创建独立 ArkTS Empty Ability 工程；
- 将 `starter/Index.ets` 放入入口页面；
- 验证 Previewer、模拟器或真机至少一种可用；
- 准备 `teacher/Index.completed.ets` 作为备用；
- 不打开或修改 `KangxiaobanAI` 正式产品源码。

## 三、教学重点

- `@Local` 改变后，使用它的界面自动更新；
- `@Param` 由父组件传给子组件，子组件不能直接修改；
- 子组件通过 `@Event` 报告点击，父组件负责真正修改状态。

## 六、课堂提问

1. 杯数属于哪个组件？
   - 答：父组件 `Index`。
2. 为什么子组件不能直接修改杯数？
   - 答：它收到的是只读 `@Param`。
3. 子组件如何通知父组件？
   - 答：调用 `@Event`。
4. 为什么 Text 会自动变化？
   - 答：它使用了可观察状态，状态改变后 ArkUI 更新界面。
5. 关闭页面后数据是否保留？
   - 答：不保留，本课没有持久化。

## 七、教师答案

```typescript
onAddWater: () => {
  this.waterCups++;
},
onToggleDone: () => {
  this.isDone = !this.isDone;
}
```

## 八、验收步骤

1. 初始为 0 杯、待完成；
2. 点击三次，显示 3 杯；
3. 点击完成任务，显示已完成和恢复待办；
4. 再点一次，恢复待完成；
5. 搜索代码，确认没有 V1 装饰器；
6. 让学生用自己的话解释数据流。

## 九、课堂常见错误

| 错误 | 纠正方式 |
|---|---|
| 写成 `this.waterCups + 1` | 必须赋值或使用 `++` |
| 写成 `this.isDone = true` | 改为 `this.isDone = !this.isDone` |
| 在子组件直接改 `@Param` | 调用 `@Event`，让父组件修改 |
| 使用 `@State` | 改用 V2 的 `@Local` |
| 声称数据已保存 | 明确只是内存状态，没有服务器或数据库 |

更详细的话术、DevEco 操作和排错方法见 `BABYSITTER_GUIDE.md`。
