# 学生作业：长者关怀看板

## 一、作业主题

使用一份 ArkTS 页面代码，完成手机与宽屏设备的响应式布局。

完成后应看到：

- 窄窗口：长者信息卡在上，今日任务卡在下；
- 宽窗口：长者信息卡在左，今日任务卡在右；
- 页面顶部会显示“手机单列”或“宽屏双栏”；
- 宽屏时左右留白更大，正文保持合理宽度。

预计用时：70～100 分钟。

## 二、学习目标

完成作业后，你应能解释：

1. “一次开发，多端部署”不等于把手机页面机械放大；
2. 为什么布局应优先按窗口宽度判断，而不是按设备名称判断；
3. `GridRow`、`GridCol`、`columns` 和 `span` 分别做什么；
4. `xs`、`sm`、`md`、`lg`、`xl` 断点如何控制单列与双栏；
5. `onBreakpointChange` 为什么要修改 `@Local` 状态。

## 三、准备练习工程

1. 在 DevEco Studio 新建独立的 `Empty Ability` 工程；
2. 开发语言选择 ArkTS，模型选择 Stage；
3. SDK/API 优先选择 API 24；
4. 打开模块的 `src/main/module.json5`，确认包含：

```json5
"deviceTypes": [
  "phone",
  "tablet",
  "2in1"
]
```

5. 找到 `entry/src/main/ets/pages/Index.ets`；
6. 用本作业 `starter/Index.ets` 整体替换入口页面；
7. 保存并运行一次，确认起始代码能显示页面。

不要把 V1 的 `@State` 与本作业的 V2 写法拼在一起。

## 四、理解起始效果

起始代码故意保留 4 个 TODO，因此会有两个现象：

1. 页面在不同宽度下暂时一直显示“手机单列”；
2. 长者信息卡和任务卡在宽屏下仍然上下排列。

这不是故障，而是本次作业需要完成的内容。

## 五、基础任务

### TODO 1：记录当前断点

找到：

```typescript
.onBreakpointChange((breakpoint: string) => {
  // TODO 1
})
```

把回调收到的 `breakpoint` 保存到父组件的 `currentBreakpoint`。

完成后，改变窗口宽度时，顶部标签应在“手机单列”和“宽屏双栏”之间变化。

### TODO 2：设置左侧长者信息卡的跨度

找到第一个 `GridCol` 的 `span`。

要求：

| 断点 | 网格总列数 | 左侧卡片占用列数 |
|---|---:|---:|
| `xs` | 4 | 4 |
| `sm` | 4 | 4 |
| `md` | 8 | 3 |
| `lg` | 12 | 4 |
| `xl` | 12 | 4 |

`xs/sm` 占满一行；`md`、`lg` 和 `xl` 只占左侧部分。

### TODO 3：设置右侧任务卡的跨度

找到第二个 `GridCol` 的 `span`。

要求：

| 断点 | 网格总列数 | 右侧卡片占用列数 |
|---|---:|---:|
| `xs` | 4 | 4 |
| `sm` | 4 | 4 |
| `md` | 8 | 5 |
| `lg` | 12 | 8 |
| `xl` | 12 | 8 |

检查同一断点下左右列数之和：

```text
xs/sm：4（左卡单独一行）+ 4（右卡单独一行）
md：3 + 5 = 8
lg/xl：4 + 8 = 12
```

### TODO 4：设置响应式页面边距

找到 `pagePadding()`。

要求：

- `xs` 和 `sm` 返回 `16`；
- `md`、`lg` 和 `xl` 返回 `32`。

不要复制两套页面。只让同一个方法根据当前断点返回不同数值。
