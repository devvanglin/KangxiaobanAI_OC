**结构要点**：`run_agent.py`（AIAgent facade，turn 循环在 `agent/turn_*.py`）· `model_tools.py`（工具编排）· `toolsets.py`（`_HERMES_CORE_TOOLS`）· `hermes_state.py`（SessionDB facade + 21 个 `hermes_state_*.py`）· `tools/`（注册式发现，`tools/registry.py` 无依赖）· `gateway/`（run.py facade + 15 siblings + platforms/ 每平台一适配器）· `plugins/`（memory/context_engine/kanban/image_gen/video_gen/observability 等，model-providers 40 家）· `skills/`（内置 60 个 SKILL.md）/ `optional-skills/`（137 个，默认不启用）· `optional-mcps/`（65 个 MCP 服务器目录）· `tools/mcp_tool*.py`（22 个文件的完整 MCP 客户端：发现/OAuth/健康检查/生命周期/采样/传输/服务端）。

**架构不变量（值得抄的理念）**：
1. **每会话 prompt 缓存神圣** —— 任何中途改系统提示/换工具集/重载记忆都会作废缓存前缀、放大成本；改状态类命令默认*延迟生效*（下个会话），提供 `--now` 显式立即生效。
2. **核心是窄腰** —— 每个工具每次 API 调用都要发给模型，新增能力按 Footprint Ladder 逐级：扩展现有代码 → CLI 命令+技能 → service-gated 工具(`check_fn`) → 插件 → MCP 服务器 → 核心工具（最后手段）。
3. **surface 能力归属会话而非进程环境** —— 不用 `HERMES_DESKTOP=1` 这类 env 判定，用 toolset + session 来源解析。
4. **facade + siblings 拆分** —— 每个 god file 拆成 facade + `<stem>_<topic>.py`；>2000 行或函数 >300 行/CC 30 就拆。
5. 依赖全部带上界精确 pin（防 supply-chain），`requires-python >=3.11,<3.14`。
6. 测试：只写行为契约（invariant），禁止 change-detector 与"读源码文本"的测试；统一走 `scripts/run_tests.sh`。

**技能格式**（可直接借鉴给康小伴 Skills 管理模块）：`SKILL.md` + YAML frontmatter = `name` / `description`（≤60 字符、一句、句号结尾）/ `version` / `author` / `license` / `platforms`（OS 门控）/ `metadata.hermes.{tags,category,related_skills,config}` / `prerequisites.commands`；正文含 `## Prerequisites` / `## When to Use`；由 `tests/skills/test_authoring_standards.py` 强制校验。

**与康小伴的潜在接口**：康小伴 `WideModelManagement.ets` 的模块导航是 `模型管理 / 提示词库 / MCP 管理 / Skills 管理 / RAG 知识库`，其中 **MCP 管理与 Skills 管理目前是 `wipModule` 占位**；后端 Go 侧尚无 skills/MCP 实现。Hermes 的 skills 格式、MCP 客户端、memory 插件 ABC（mem0/honcho/supermemory/hindsight/byterover/retaindb）可直接作为这两块的参考实现。

## 产出：Hermes Agent 架构解析文档

已写 `docs/hermes-agent-architecture.md`（康小伴工作区自有目录，不污染 hermes 仓库）。内容基于源码 + `agent/AGENTS.md` + `website/docs/developer-guide/{architecture,agent-loop,prompt-assembly,context-compression-and-caching}.md`。

**核心事实备查**：
- AIAgent = `run_agent.py` facade（1558 行）+ mixins；构造 `agent/agent_init.py`；循环 `agent/conversation_loop.py`；20+ 个 `agent/turn_*.py` 分阶段。入口 `chat(msg)->str` / `run_conversation(...)->dict`。
