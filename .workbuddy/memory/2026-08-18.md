## 康养雷达 MQTT Broker 部署(用户服务器)

在用户服务器上完成 EMQX 部署,用于承接养老院毫米波雷达的 MQTT 数据。

### 服务器信息
- 地址:`192.168.100.110`(Ubuntu 22.04.5 LTS 虚拟机,PVE 上的 QEMU 虚机,hostname pve-Standard-PC-Q35-ICH9-2009)
- 登录用户:`pve`(uid 1000,在 sudo 组,但**不在 docker 组**,docker 需 sudo)
- Docker 版本:29.7.2

### 部署结果(已验证)
- EMQX 容器:`emqx/emqx:latest`,`--restart=always` 开机自启
- 端口:1883(MQTT)、8083(WebSocket MQTT)、18083(Dashboard)
- 验证:容器 Up、三端口监听、Dashboard HTTP 200、1883 TCP 握手成功、本机(192.168.100.110:18083)内网可达
- Dashboard 默认账号:`admin / public`;MQTT 匿名连接默认开放(EMQX 5.x allow_anonymous=true)

### 雷达配网要填的信息

### 技术备忘
- SSH 方式:Windows 本机用 paramiko(managed python 3.13.12 已 pip install)+ 密码认证;本机无 sshpass
- sudo 密码管道:`echo '<pass>' | sudo -S -p "" bash -c '<cmd>'`
- EMQX 5.x REST API 用 admin/public Basic auth 报 BAD_API_KEY_OR_SECRET(需 token/api_key);查客户端改用 `docker exec emqx emqx ctl clients list`(需 sudo)
