# 第一部分:monitor_fall.py(跌倒监控)

## 0. 脚本整体在干什么

一句话:连接 MQTT 服务器 → 订阅跌倒雷达的数据 → 收到一条打印一条 → 如果是"跌倒"就大声报警。

---

## 1. 文件头(第 1~13 行)

```python
#!/usr/bin/env python3      # 告诉系统用 python3 跑(可忽略)
# -*- coding: utf-8 -*-      # 声明文件编码是 UTF-8,支持中文
"""
跌倒雷达实时监控脚本
... (三引号里是注释,给人看的说明文字)
"""
```

这三段都是**注释和声明**,不参与运行,只是给人看的说明。

## 2. 导入库(第 15~17 行)

```python
import paho.mqtt.client as mqtt   # 导入 MQTT 通信库,起个简称 mqtt
import json                        # 导入 JSON 解析库
import time                        # 导入时间库
```

- `import` = 把别人写好的工具拿进来用
- `paho.mqtt.client` = 专门处理 MQTT 通信的库(连接、订阅、收消息)
- `json` = 处理 JSON 格式数据
- `time` = 拿当前时间

## 3. 配置(第 19~20 行)

```python
BROKER = "192.168.100.110"   # MQTT 服务器的 IP 地址
DEVICE = "E438192584AA"       # 要监控的雷达设备 ID
```

两个**变量**,等于给这两个值起了名字。换一台设备,只改 `DEVICE` 这一行。

## 4. 字段中文对照表(第 22~32 行)

```python
FIELD_LABELS = {
    "online": "在线",
    "someoneExists": "有人",
    ...
    "fallStatus": "跌倒报警",
}
```

一个**字典(dict)**,左边是雷达发来的英文字段名,右边是给用户看的中文名。作用:收到 `fallStatus` 时,屏幕上显示"跌倒报警"而不是一串英文。

## 5. 核心函数 on_message(第 35~49 行)

这是整个脚本的**心脏**,每当收到一条雷达消息,这个函数就自动被调用一次。

```python
def on_message(client, userdata, msg):
```
定义函数,`msg` 就是收到的那条消息。

```python
    try:
        data = json.loads(msg.payload)
    except Exception:
        return
```
把消息内容(JSON 文本)解析成 Python 能读的数据。`try/except` 是保护:万一收到的是乱码,解析失败就直接 `return`(跳过),不让程序崩溃。

```python
    params = data.get("params", {})
```
从数据里取出 `params` 部分(真正的数值都在这里),取不到就给个空字典。

```python
    ts = time.strftime("%H:%M:%S")
```
拿当前时间,格式化成"时:分:秒"。

```python
    for k, v in params.items():
```
遍历 params 里的每一对"字段名(k)和值(v)"。比如 `{"breathValue":"18"}` 就循环一次,k=breathValue,v=18。

```python
        label = FIELD_LABELS.get(k, k)
```
把英文字段名 k 翻译成中文 label;如果对照表里没有,就原样显示。

```python
        if k == "fallStatus" and str(v) == "1":
            print("=" * 44)
            print("  >>>>> 跌倒报警触发!  <<<<<")
            print("=" * 44)
```
**关键判断**:如果这个字段是"跌倒状态"且值是"1",就打印一大串醒目的报警。

```python
        else:
            print(f"[{ts}] {label} = {v}")
```
否则,正常打印一行:`[时间] 中文名 = 值`。

## 6. 主函数 main(第 52~60 行)

```python
def main():
    topic = f"/Radar60FL/{DEVICE}/sys/property/post"
```
拼出要订阅的"主题"。`f"..."` 里的 `{DEVICE}` 会被替换成设备 ID,所以最终是 `/Radar60FL/E438192584AA/sys/property/post`。

```python
    client = mqtt.Client(client_id="fall_monitor")
```
创建一个 MQTT 客户端,`client_id` 是给自己起的名字(服务器用它区分是谁)。

```python
    client.on_message = on_message
```
**关键的一行**:告诉客户端"每当收到消息,就调用上面写的 on_message 函数"。这叫**回调**——你不用一直盯着,消息来了它自动喊你。

```python
    client.connect(BROKER, 1883, 60)
```
连接服务器(IP + 端口 1883),60 是心跳超时秒数。

```python
    client.subscribe(topic)
```
订阅那个主题——相当于告诉服务器"这个主题的消息请都发给我"。

```python
    client.loop_forever()
```
**让程序一直跑,永远不退出**。死循环监听消息,一有消息就触发 on_message。

## 7. 程序入口(第 63~64 行)

```python
if __name__ == "__main__":
    main()
```

固定写法:当这个文件被直接运行时(而不是被别的地方导入),执行 main()。

# 第二部分:monitor_sleep.py(呼吸心率监控)

## 和跌倒脚本的区别(只有 3 处)

| 位置 | fall 脚本 | sleep 脚本 | 为什么 |
|---|---|---|---|
| DEVICE | E438192584AA | E438192584F5 | 不同设备 |
| topic 前缀 | /Radar60FL/ | /Radar60SP/ | FL=跌倒,SP=睡眠 |
| FIELD_LABELS | 跌倒相关字段 | 呼吸/心率/睡眠字段 | 字段不同 |

## sleep 脚本多出来的东西

```python
SLEEP_STATE = {"0": "深睡", "1": "浅睡", "2": "清醒", "3": "无/离床"}
```
睡眠状态的数字→中文对照。

```python
def fmt(field, value):
    ...
```
一个辅助函数:给枚举字段加中文解释。比如收到 `sleepStatus=1`,显示成 `1(浅睡)`,而不是干巴巴的"1"。

其余逻辑和跌倒脚本完全一样:连接 → 订阅 → 收到就打印。

# 第三部分:三个核心概念(必懂)

## 概念 1:回调函数(callback)

```python
client.on_message = on_message
```

你不需要写"一直循环检查有没有消息"这种代码。你把 `on_message` 这个函数"交给"了客户端,消息一来,客户端**自动**调用它。这就是**事件驱动**:

> 事件(收到消息)发生 → 自动触发函数(处理消息)

## 概念 2:JSON

雷达发的消息是一串文本:

```json
{"version":"1.0","method":"post","params":{"breathValue":"18"}}
```

`json.loads()` 把它变成 Python 的字典,你就能用 `.get("params")` 取出数值。就像把一封信拆开,抽出里面的"呼吸=18"这张纸条。

## 概念 3:Topic 订阅

```
/Radar60FL/设备ID/sys/property/post
```

- 你订阅了它,就收到"这台设备的上报数据"
- 服务器像按地址分发邮件,你只收你订阅的那个地址
