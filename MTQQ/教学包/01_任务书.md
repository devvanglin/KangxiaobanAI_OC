# 毫米波雷达养老监护系统 · 搭建任务书

> 适用对象:养老院技术员、物联网入门学员
> 前置要求:会开电脑、会用浏览器,无需编程基础
> 预计时长:90 分钟
> 配套文件:教材、代码讲解、教师逐字稿(同目录)

---

## 一、任务概述

用两台 60G 毫米波雷达 + 一台 MQTT 服务器,搭出一套"房间无感监护"系统:

- **跌倒雷达**(R60AFD1):装在卫生间,人摔倒自动报警
- **呼吸心率雷达**(R60ASM1):装在卧室,监测呼吸、心率、睡眠

数据全部走 MQTT 协议,最后用 Python 脚本实时看到数值。本任务书带你从零一步步搭出来。

## 二、学习目标(做完你会什么)

1. 能部署一个 MQTT 服务器(EMQX)
2. 能给雷达配网(连接 WiFi + 填服务器地址)
3. 能下发参数(场景、安装高度、灵敏度)
4. 能运行脚本实时看呼吸/心率/跌倒数据
5. 理解"雷达 → Broker → 订阅端"这条数据链路

## 三、物料清单

|---|---|---|

## 任务一:部署 MQTT 服务器

**目标**:让服务器上跑起一个 EMQX,雷达数据都往这发。

**步骤**:
1. 确认服务器装了 Docker,执行:
   ```bash
   docker run -d --name emqx --restart=always \
     -p 1883:1883 -p 8083:8083 -p 18083:18083 emqx/emqx
   ```
2. 浏览器开 `http://<服务器IP>:18083`,账号 `admin`、密码 `public`,能打开即成功
3. **记下两个数**:服务器 IP、端口 `1883`(下一步配网要用)

**验收**:能打开 EMQX 后台页面。

## 任务二:雷达配网(每台都做一遍)

**目标**:让雷达连上 WiFi,并告诉它数据发到哪。

雷达只有一个按键,**长按时长不同进不同模式**,务必分清:

| 长按 | 出现 | 用途 |
|---|---|---|
| 10 秒以上 | WiFi 热点 `RadarConfig-xxxx` | 填 MQTT 服务器地址 |
| 长按到灯闪 | 蓝牙 `Radar_BLE` | 连 WiFi |

**2.1 填服务器地址**:
1. 长按 **10 秒以上** → 手机连热点 `RadarConfig-xxxx`
2. 浏览器开 `192.168.0.1`
3. 填:服务器地址 `tcp://<服务器IP>:1883`,用户名/密码留空,ClientID 填设备ID
4. 点「修改」→「设置完成,退出」

**2.2 连 WiFi**:
1. 长按按键,**一直按住别松,LED 亮→灭→闪烁,灯闪了才松手**
2. 手机开蓝牙,打开 APP「BK BLE WIFI」
3. 选蓝牙 `Radar_BLE` → 选 2.4G WiFi → 填密码 → 配网
4. 提示 `Network configuration successful` = 成功

**2.3 抄设备 ID**:配网页顶部那串(如 `E438192584F5`),记下来,两台都要。

**验收**:配完两台,服务器上能看到两个设备在线。

## 任务三:下发参数

**目标**:告诉雷达"你装在什么房间、多高、灵敏度多少",算法才准。

用 MQTT 客户端(或让老师帮你)对每台设备发 set 命令:

| 设备 | 场景模式 | 安装高度 | 其他 |
|---|---|---|---|
| 跌倒雷达(卫生间) | 3 | 230cm | 灵敏度 3、**跌倒确认时长 5** |
| 呼吸雷达(卧室) | 2 | 按实际 | **上报模式 0(实时)** |

**验收**:雷达回复 `success`。

### ⚠️ 两个必设的隐藏开关(新手必踩)

这两个开关默认值都不对,**不设的话功能不工作**,务必检查:

| 开关 | 设备 | 默认值 | 要改成 | 不设的后果 |
|---|---|---|---|---|
| `fallDuration` 跌倒确认时长 | 跌倒雷达 | 20 秒 | 5 秒(最小) | 躺不够 20 秒不报警,以为雷达坏了 |
| `reportMode` 上报模式 | 呼吸雷达 | 1(睡眠传输) | 0(实时传输) | 呼吸心率数值一个都不吐 |

> 这两个是实战踩出来的坑,记住:跌倒雷达看 `fallDuration`,呼吸雷达看 `reportMode`。

## 任务四:运行监控脚本

**目标**:用 Python 脚本实时看到雷达数据。

1. 装依赖:`pip install paho-mqtt`
2. 跑跌倒监控:`python monitor_fall.py`
3. 跑睡眠监控:`python monitor_sleep.py`

**验收**:脚本打印出「正在监控」,有数据持续刷出。

## 任务五:验证三大功能

| 功能 | 怎么触发 | 看到什么 |
|---|---|---|
| 有人/无人 | 走出探测区(3米)等30秒,再走回 | 刷出「有人=0」「有人=1」 |
| 跌倒报警 | 站立→突然躺平→不动6秒 | 刷出「跌倒报警触发!」 |
| 呼吸心率 | 躺床上保持静止 | 呼吸数值、心率持续刷新 |

## 常见问题速查

| 问题 | 原因 | 解决 |
|---|---|---|
| 雷达连不上网 | WiFi 是 5G | 换 2.4G 频段 |
| 配网灯不闪 | 松手太早 | 长按到灯灭后继续按住,灯闪了再松 |
| 跌倒不报警 | 躺的时长不够 | 确认"跌倒确认时长"调到 5 秒,躺够 6 秒 |
| 看不到呼吸心率 | 人没静止 | 躺床上保持不动几秒 |
| 服务器没设备 | 雷达断电了 | 检查电源,通电等 1~2 分钟重连 |
